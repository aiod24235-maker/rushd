# نظام نقاط نادي رُشد

تطبيق ويب عربي RTL لإدارة عضويات ونقاط نادي رُشد بجامعة المجمعة. لا يعتمد على أي حزم خارجية؛ قاعدة البيانات الفعلية SQLite في `roshd.db` وتُنشأ وتُهيّأ تلقائيًا عند التشغيل.

## التشغيل

```powershell
$env:ADMIN_PASSWORD = "كلمة-مرور-آمنة"
node server.js
```

ثم افتح `http://localhost:3000`. إن لم تحدد متغير `ADMIN_PASSWORD` عند التشغيل، تكون كلمة مرور الإدارة التجريبية `Roshd@2026` — غيّرها قبل النشر.

## ما يتضمنه

- تسجيل أعضاء عام وحفظ الطلب بحالة قيد المراجعة ومنع تكرار الرقم الجامعي.
- لوحة إدارة محمية بجلسة HttpOnly لقبول/رفض/تعديل/حذف الأعضاء وإدارة الأنشطة وسجل النقاط.
- إضافة نقاط آلية مع سجل قابل للحذف (ويُخصم أثره عند الحذف).
- مستويات وترتيب محسوبان للأعضاء المقبولين فقط.
- بطاقة عضو عامة محمية بحالة القبول ولا تعرض رقم الجوال، وبها باركود Code 128-B.
- بيانات تجريبية وأنشطة النادي العشرة عند أول تشغيل.

## النشر

اضبط `PORT` و`ADMIN_PASSWORD` لدى مزود الاستضافة، واحفظ ملف `roshd.db` ضمن قرص دائم/Volume حتى لا تضيع العضويات والسجلات بعد إعادة التشغيل.

### نشر Render

يتضمن المشروع `render.yaml` و`Dockerfile`. ارفعه إلى مستودع GitHub جديد، ثم من Render اختر **New → Blueprint** واربط المستودع. سيُنشأ القرص الدائم تلقائيًا ويُستخدم `DATABASE_PATH=/var/data/roshd.db`. بعد أول نشر، انسخ قيمة `ADMIN_PASSWORD` التي ولّدها Render إلى مكان آمن لاستخدامها في لوحة الإدارة.
